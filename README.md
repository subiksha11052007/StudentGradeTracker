# Student Grade Tracker

## Project Description
Student Grade Tracker is a Java-based application developed to manage student records and analyze academic performance. This project allows users to add student details, store marks, calculate average marks, identify highest and lowest scores, generate grades, and save records into a file.

This project was developed as part of the CodeAlpha Java Programming Internship.

---

## Features
- Add student details
- Store marks for multiple subjects
- Calculate average marks
- Find highest marks
- Find lowest marks
- Generate grades
- Search student by ID
- Delete student record
- Generate class report
- Find topper
- Calculate class average
- Save records into file
